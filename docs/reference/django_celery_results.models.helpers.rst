=====================================================
 ``django_celery_results.models.helpers``
=====================================================

.. contents::
    :local:
.. currentmodule:: django_celery_results.models.helpers

Use these helpers when code needs the active result models for the current
Django project. They return the default django-celery-results models unless a
project configures swappable task, group, or chord counter models.
